- [SuperbulletFrameworkV1-Knit](https://github.com/Froredion/SuperbulletFrameworkV1-Knit)
  is a public Knit-based wrapper emphasizing modular services, readable startup
  errors, IntelliSense, and portable components. Its repository states an
  MIT-like license for extensions; verify the actual license before redistribution.
- [SuperbulletAI-Issues](https://github.com/Froredion/SuperbulletAI-Issues) is an
  issue-reporting repository, not a framework or quality certification.
- [SuperBullet Marketplace](https://marketplace.superbullet.ai/store) is an asset
  source, but each item's license and redistribution rights must be verified.

## Adopted patterns, not copied implementation

The project may adopt service/component separation, explicit lifecycle boundaries,
reusable feature templates, AI-friendly error messages, asset manifests, and
prompt → inspect → implement → playtest → fix loops. Do not copy proprietary
libraries, hidden prompts, marketplace assets, or code without permission.

Roblox Creator Hub is authoritative for engine behavior, security, remotes,
performance, and publication policy. The master prompt is authoritative for
approvals, SDT, agents, and closure.
