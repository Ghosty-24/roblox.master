## Criterios de aceptación visual

- [ ] La cámara reproduce el encuadre y el punto focal de la referencia.
- [ ] Las masas principales respetan sus proporciones relativas.
- [ ] Las rutas y espacios negativos mantienen una lectura equivalente.
- [ ] Los elementos repetidos conservan cantidad aproximada, separación y alineación.
- [ ] Los colores, materiales e iluminación siguen la dirección visual aprobada.
- [ ] No se añadieron elementos fuera de la especificación aprobada.
- [ ] Existe una captura comparable desde el ángulo acordado.

## Plan de verificación

1. Capturar la referencia y la escena desde un encuadre comparable.
2. Revisar primero composición y masas grandes.
3. Revisar después materiales, color e iluminación.
4. Revisar por último detalles y decoración.
